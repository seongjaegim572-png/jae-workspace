# Jae 작업 공간

Jae가 Claude Code와 함께 일하는 공간이에요.

## 폴더
- `projects/` — 진행 중인 프로젝트
- `notes/` — 메모와 아이디어
- `CLAUDE.md` — Claude가 지키는 규칙

## 사용법
1. Claude Code에서 이 저장소를 열어요.
2. 하고 싶은 일을 한국어로 말해요. 예: "notes에 오늘 아이디어 정리해 줘"
3. Claude가 만든 결과를 보고, 마음에 들면 저장(커밋)해 달라고 해요.

## 주의
- 게시, 제출, 결제, 연락은 Jae가 직접 해요.
- 비밀번호, API 키, 환자·건강·군 관련 정보는 여기에 넣지 않아요.
