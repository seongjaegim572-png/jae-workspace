# Halo — 그래뉼러 + 웨이브테이블 신스 (VST3 / AU)

Omnisphere 같은 "분위기/패드/텍스처" 신스. 레이어 2개를 겹쳐요.
Omnisphere의 거대한 사운드 라이브러리는 없어요. 대신 **내 샘플(WAV/루프)을 끌어다 놓으면** 바로 패드·텍스처로 바뀌어요.

## 기능
- **레이어 A/B**: 각각 Wavetable(8종) 또는 Granular
  - Granular: Grain Pos, Spray, Size, Density, Pitch Jitter
  - 텍스처 5종(내장 합성): Glass Choir, Air, Bowed, Shimmer, Dusty Tape + **User Sample**
  - 레이어마다 필터(LP/BP/HP)와 ADSR
- **Load Sample** 버튼 또는 창에 WAV 드래그 → 레이어 A가 그 샘플로 그래뉼러 재생. Root 노브 = 샘플의 원래 음
- LFO 2개, Mod Env, 모드 매트릭스 4칸, 매크로 2개
- **아르페지에이터**: Up / Down / Up-Down / Random / As Played, 1~3 옥타브, Gate
- FX: Dist, Chorus, Delay(템포 싱크), Reverb

## 프리셋 9개
Glass Cathedral, Wind Pad, Bowed Dream, Shimmer Keys(아르프), Dusty Tape Pad, Choir Arp, Glitch Texture, Your Sample Pad, Init

## 루프스테이션 팁
루프 녹음 → WAV로 저장 → Halo에 드래그 → Spray·Size 올리면 루프가 패드처럼 번져요.
