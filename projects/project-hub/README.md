## 분류 규칙

**중요** = 아래 셋 중 하나에 직접 도움이 됨
1. 편입 / 음악 커리어
2. 돈 (병원 마케팅, 크리에이터 수입)
3. 막혀 있는 다른 일을 풀어 줌

**급함** = 2주 안에 마감이 있거나, 이미 늦어지고 있음

**처리 순서**
1. ①을 먼저. 한 번에 하나만.
2. ③은 5분 안에 끝나면 바로 끝내고, 아니면 맡기기.
3. ②는 캘린더에 시간 박기. 안 박으면 영원히 안 함.
4. ④는 세션 보관. 아까워하지 않기.

**규칙**
- ① 칸이 3개를 넘으면 새 프로젝트 시작 금지.
- 새 세션을 열면 여기 한 줄 추가.

## 업데이트 방법

새 Claude Code 세션에서 이렇게 말하면 돼요:

> "프로젝트 관제탑 업데이트해 줘"

Claude가 할 일:
1. 내 세션 목록을 읽는다.
2. 새 세션 / 끝난 세션 / 막힌 세션을 찾는다.
3. 박스를 다시 나누고, "오늘 5분 할 일"을 하나 고른다.
4. 이 파일을 고치고 커밋한다.

주간 점검: 매주 금요일 한 번 (편입 요약, 병원 SNS 요약과 같이).
