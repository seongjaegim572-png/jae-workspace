# 대표 사진 시안 v2 (초안, 2026-11-14)

v1(남색 배경 + 원장님 누끼 + 글 4줄)은 Jae가 "과최적화, 별로"라고 해서 버림.

## v1이 별로였던 이유
- 메시지가 4개(투석, 입원, 소아과 30년, 병원 이름) → 아무것도 안 남음
- 소아과 원장님 사진 + 인공신장실 문구가 서로 안 맞음
- 남색 단색 + 빨간 띠 = 흔한 광고 배너처럼 보임. 지도 썸네일에선 글이 안 읽힘

## v2 원칙

- 사진 1장 = 메시지 1개
- 홈페이지에 있는 사실만 씀 (1층 인공신장실, 인공신장기 13대, 29병상, 무료 주차)
