# 병원 사진 찍을 목록 (2026-11-14, 계획)

목적: 네이버 플레이스(검색 많음) + 홈페이지에 같이 쓰기. 플레이스 먼저.
지금 문제: 사진이 작고(인공신장실 676px), 인공신장실 사진 1장을 메인·투석 페이지에 같이 씀.

## 찍는 법 (휴대폰, 10분)
- 가로로, 낮 시간, 불 다 켜고, 창문 등지고 찍기
- 환자 얼굴·이름표·모니터 화면 나오지 않게. 직원은 동의받은 경우만
- 원본 그대로 Claude에게 주면 줄이고 사이트에 넣음

## 찍을 것 (매출 순서)
1. 인공신장실 전체 (입구에서 넓게) — 플레이스 1번 사진
2. 투석 침대 1자리 가까이 (침대·TV·담요, "4시간 편하게"가 보이게)
3. 1층 입구 → 인공신장실 가는 길 (계단 없음이 보이게)
4. 정문 앞 주차장 (차 대는 위치에서)
5. 입원실 (침대 정리된 상태, 창문 쪽)
6. 입원 식사 한 상 (이사장님 관리 식단)
7. 접수·대기실
8. 원장님 진료실 (원장님 동의 시)
