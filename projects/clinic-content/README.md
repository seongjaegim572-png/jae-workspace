# 병원 콘텐츠 공장 (미래연합의원)

원장님 메모 하나 → 스레드 글, 네이버 블로그 글, 인스타 캡션으로 바꾸는 프로젝트예요.

## 파일
- `tone-rules.md` — 잘 된 글에서 뽑은 제목·톤 규칙
- `drafts/` — 아직 안 올린 글 초안
- `print/` — 인쇄해서 쓰는 종이 (접수용 기록표 등)
- `tool/index.html` — 콘텐츠 공장 도구. 브라우저로 열면 바로 써요 (인터넷·API 키 필요 없음)

## 상태
- 완료: 스레드 상위 글 5개로 제목 규칙 초안 만들기
- 완료 (v1, 2026-11-16): 메모 → 제목 5개 + 스레드·블로그·인스타 초안 + 의료광고 표현 체크 (`tool/`)
- 계획: 실제 글 2~3개에 써 보고 고칠 점 모으기 → 다른 의원도 쓸 수 있게 병원 정보 설정 분리 → AI로 본문 살 붙이기(v2)

## 넣지 않는 것
- 환자 이름, 얼굴, 진료 내용 등 환자 정보
- 계정 비밀번호
