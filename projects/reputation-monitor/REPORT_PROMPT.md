# 평판 주간 보고 만드는 법 (Claude용)

예약 작업이 매주 이 파일을 읽고 그대로 따른다.

## 1. 새 글 모으기
```
cd projects/reputation-monitor && python3 monitor.py
```
`out/new_items.json`에 새 글이 들어간다. `errors`가 있으면 보고서 맨 끝에 적는다.
새 글이 0개이면 2번을 건너뛰고 "새 글 없음"으로 짧게 보고한다.

## 2. 글마다 판단하기
`own: true`(병원 블로그·인스타·홈페이지)는 우리가 쓴 글이다. 개수만 센다.
나머지는 제목·요약을 읽고, 애매하면 원문을 WebFetch로 열어 본다. 각 글을 아래 중 하나로 나눈다.

| 분류 | 뜻 |
|---|---|
| 무관 | 다른 지역 동명 병원(충주·대구 대곡·경산 등), 동명이인 "양윤정", 제주 남원읍 등 |
| 긍정 | 칭찬, 감사, 추천, 좋은 언론 보도 |
| 중립 | 채용 공고, 단순 목록, 질문 |
| 부정 | 불만, 나쁜 후기, 비판 |
| 정보 오류 | 병원 정보가 틀리게 퍼진 글 (예: 야간투석을 한다고 적힘, 옛 진료시간) |

남원 미래연합의원(남원시 시청로 3)과 관련 있는지 먼저 확인한다. 확실하지 않으면 "무관"이 아니라 "확인 필요"로 둔다.
사실 기준은 `projects/clinic-website/site.json`과 `projects/clinic-website/README.md`의 "확인 완료" 항목이다.

## 3. 보고서 쓰기
`reports/YYYY-MM-DD.md`에 아래 틀로 쓴다. 쉬운 말로 짧게.

```
# 미래연합의원 평판 주간 보고 (YYYY-MM-DD)
채널: 네이버 블로그·카페·뉴스·지식iN / 검색어: config.json

## 한 줄 요약
(예: 부정 글 0건. 정보 오류 1건 계속 확인 필요.)

## 바로 할 일 (없으면 "없음")
- 가장 중요한 일 1개만 맨 위에

## 지켜볼 항목
| 항목 | 지난주 | 이번 주 | 판정 (🟢 괜찮음 / 🟡 지켜보기 / 🔴 대응 필요) |

## 이번 주 새 글
- 긍정 N / 중립 N / 부정 N / 정보 오류 N / 무관 N / 우리 글 N
- 무관이 아닌 글만 한 줄씩: [분류] 날짜 · 채널 · 제목 · 링크 · 한 줄 설명

## 가족방에 보낼 3줄
(카톡에 그대로 붙여넣을 수 있게. 존댓말, 이모지 1~2개, 링크 없이)
```

"지켜볼 항목"은 지난주 보고서(`reports/`의 가장 최근 파일)의 표를 이어받는다. 해결된 항목은 🟢로 바꾸고 다음 주에 뺀다.

## 4. 개인정보 규칙
- 저장소에는 환자 이름, 병명, 개인 사정을 쓰지 않는다. 후기 내용은 "투석 후기, 친절 칭찬"처럼 뭉뚱그린다.
- 글쓴이 닉네임도 쓰지 않는다. 링크만 남긴다.

## 5. 보내기
- Gmail로 **Jae 본인에게만** 보낸다. 제목: `[평판 보고] 미래연합의원 YYYY-MM-DD`. 본문은 보고서 내용 그대로.
- 다른 사람(가족 포함)에게 직접 보내지 않는다. 가족방 공유는 Jae가 "가족방에 보낼 3줄"을 복사해서 한다.

## 6. 저장
`state/seen.json`과 `reports/YYYY-MM-DD.md`를 커밋하고 push한다. `out/`은 커밋하지 않는다.
