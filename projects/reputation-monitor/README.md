# 미래연합의원 평판 모니터

네이버 블로그·카페·뉴스·지식iN에서 "미래연합의원" 새 글을 모으고, Claude가 긍정·부정·정보 오류를 나눠 주간 보고서를 쓴다.

- `monitor.py`: 새 글 모으기 (표준 라이브러리만 사용). `python3 monitor.py --dry-run`으로 시험 실행
- `config.json`: 검색어, 채널, 우리 채널 주소
- `REPORT_PROMPT.md`: 보고서 만드는 순서 (예약 작업이 이 파일을 따른다)
- `state/seen.json`: 이미 본 글 주소 (중복 방지)
- `reports/`: 주간 보고서

## 자동 실행
- 매주 월요일 아침(한국 시간) 예약 작업이 돌고, 보고서를 Jae의 Gmail로 보낸다.
- 가족 카톡방에는 자동으로 올리지 않는다. 카카오는 단톡방 자동 전송 API가 없고, 다른 사람에게 연락하는 일은 Jae가 직접 한다. 보고서의 "가족방에 보낼 3줄"을 복사해서 붙인다.

## 한계
- 네이버 검색 화면 구조가 바뀌면 글을 못 찾을 수 있다. 보고서의 "오류"와 찾은 글 수가 갑자기 0이 되면 고친다.
- 네이버 플레이스 방문자 리뷰는 못 읽는다. 스마트플레이스에서 직접 본다.
- 더 안정적으로 하려면 네이버 검색 API(developers.naver.com, 무료)로 바꾼다. (계획)
