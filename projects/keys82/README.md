# 82 Keys — 모델링 건반 (VST3 / AU)

Keyscape 같은 "건반 모음" 악기를 샘플 없이 합성으로 만든 것.
진짜 녹음 샘플(수십 GB)은 없어서 Keyscape만큼 사실적이진 않아요. 대신 가볍고(설치 몇 MB), 소리를 깊게 바꿀 수 있어요.

## 악기 7종
- **Grand Piano**: 줄 2개 + 비조화 배음(줄의 뻣뻣함) + 해머 소리 (모달 합성)
- **Tine EP / Reed EP**: FM 합성 + 픽업 "bark" 왜곡
- **Clav**: 뜯는 줄 모델 (Karplus-Strong) + 픽업 위치
- **Vibes / Music Box / Celesta**: 막대·금속 배음 모델

## 노브
Tone, Hardness(세게 칠수록 밝게), Decay, Release, Mechanics(해머·키 소리), Wear(낡은 악기 느낌),
Drive, Width, Velocity, Tremolo(오토팬), FX: Phaser, Chorus, Delay(템포 싱크), Reverb. 서스테인 페달 지원.

## 프리셋 11개
Concert Grand, Felt Grand, Lofi Grand, Tine EP, Tine EP Trem, Reed EP Bark, Funk Clav, Vibes, Music Box Dream, Celesta, Init
