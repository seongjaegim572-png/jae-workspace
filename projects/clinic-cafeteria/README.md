# 병원 식당 개선 (초안)

상태: **초안**. 부모님 확인 전. 금액은 대략 추정이라 실제 견적 확인 필요.

## 현재 상황
- 입원 환자 보통 10~20명, 하루 세 끼 → 하루 30~60식
- 직원 2명
- 예산: 인건비 월 500만 원 (식재료비 별도)
- 문제: 직원끼리 갈등, 조금만 힘들어도 그만두겠다는 말

## 방향
- 로봇으로 사람을 없애기보다, **역할 분리 + 교대 + 힘든 일은 기계**로 2명이 덜 부딪히게 한다.
- 한 끼 20인분 이하라 큰 자동 조리기는 필요 없다. **식기세척기 + 반조리 재료**면 충분하다.
- 위탁급식은 식수가 적어서 업체가 안 받을 가능성이 크다.

## 역할표
| | 조리 담당 (오전조) | 손질·배식 담당 (오후조) |
|---|---|---|
| 주 업무 | 아침·점심 조리, 간 보기 | 저녁 조리, 재료 손질, 배식, 설거지 |
| 책임 | 식단표대로 조리, 환자식(저염 등) 구분 | 식기세척기 돌리기, 마감 청소, 재고 체크 |
| 같이 하는 일 | 점심 배식 (11:00~14:00 겹침) | |

## 교대 근무표 (평일)
| 시간 | 오전조 | 오후조 |
|---|---|---|
| 06:00 | 출근, 아침 준비 | |
| 07:30 | 아침 배식 | |
| 11:00 | 점심 준비 | 출근, 손질 |
| 12:00 | 점심 배식 (같이) | 점심 배식 (같이) |
| 14:00 | 퇴근 | 설거지, 저녁 준비 |
| 17:30 | | 저녁 배식 |
| 19:00 | | 마감, 퇴근 |

- 각자 하루 약 7.5시간 (휴게 30분 포함 여부는 노무 확인)
- 같이 있는 시간은 점심 3시간뿐 → 갈등이 줄어든다
- 두 사람이 한 달마다 조를 바꿀지 정한다

## 주말 (해결해야 할 부분)
2명이 주 5일씩 일하면 주말 4교대가 빈다. 선택지:
1. 주말만 외부 환자식 도시락 받기 + 데우고 배식할 사람 1명
2. 주말 아르바이트 1명 (월 약 130만 원 추가 → 예산 초과 가능)
3. 지금은 어떻게 하는지 먼저 확인

## 운영 규칙
- 식단은 2주치를 미리 정해서 붙여 둔다
- 문제가 생기면 둘이 따로 말고 정해진 한 사람(원장님 또는 실장)에게 말한다
- 한 달에 한 번 10분 면담: 힘든 점 1개, 바꿀 점 1개

## 확인할 것
- 입원 환자 식대 관련 규정 (영양사·조리사 기준, 식대 가산)
- 투석 환자식 따로 필요한지
- 근무 시간과 임금 (주휴, 4대보험) 노무 확인
- 지금 주말 근무는 어떻게 하는지

## 식단 도우미 (초안 v0.1)
- 파일: `meal-planner.html` (브라우저로 열기)
- 인원(일반식, 당뇨식) 입력 → 2주 식단 + 와이마트 / 쿠팡 장보기 목록
- 당뇨식 기준은 일반 원칙만 넣음. **원장님 확인 필요**
