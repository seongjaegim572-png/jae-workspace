# 미래연합의원 홈페이지 (초안)

참고 사이트(pungnyeonjesa.com) 구조를 병원에 맞게 바꾼 정적 홈페이지예요.
HTML/CSS만 써서 어디든 무료로 올릴 수 있어요 (Cloudflare Pages, Netlify, GitHub Pages 등).

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 메인: 진료 안내, 야간투석 요약, 의료진, 진료시간, 오시는 길, FAQ |
| `dialysis/` | 인공신장실·야간투석 상세 |
| `pediatrics/` | 소아청소년과 상세 |
| `chronic-care/` | 고혈압·당뇨 관리 상세 |
| `assets/style.css` | 디자인 |
| `robots.txt`, `sitemap.xml` | 검색엔진용 |
| `llms.txt` | AI 검색(ChatGPT, Perplexity 등)용 요약 |

## SEO / GEO / AEO 에서 넣은 것
- **SEO**: 페이지마다 제목·설명·canonical, "남원 + 진료" 키워드, 주소·전화(NAP) 통일, sitemap, 모바일 대응
- **로컬/GEO**: `MedicalClinic` 구조화 데이터(주소, 좌표, 진료시간, 인근 지역), 네이버 지도 링크 자리
- **AEO**: 질문형 제목 + 바로 아래 한 줄 답("네. 2026년 10월부터…"), `FAQPage` 구조화 데이터
- **AI 검색**: `llms.txt`, robots.txt에서 AI 크롤러 허용, 원장 정보(`Physician`)와 검토일(`lastReviewed`)로 신뢰 표시

## 참고 사이트와 다르게 한 것
- **후기·별점은 뺐어요.** 의료법상 치료 후기 광고는 문제가 될 수 있어요.
- "최고", "완치", "무조건" 같은 말은 안 썼어요.
