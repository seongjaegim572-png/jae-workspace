# 미래연합의원 홈페이지

참고 사이트(pungnyeonjesa.com)처럼 SEO·GEO·AEO를 고려해 만든 병원 홈페이지예요.
HTML/CSS만 써서 무료 호스팅(Cloudflare Pages, Netlify, GitHub Pages)에 그대로 올릴 수 있어요.

## 페이지 (6개)
| 주소 | 내용 | 노리는 검색어 |
|---|---|---|
| `/` | 메인: 진료 안내, 의료진, 진료시간, 오시는 길, 건강 칼럼, FAQ | 남원 병원, 남원 의원 |
| `/dialysis/` | 1층 인공신장실, 병원 옮기기, 산정특례 | 남원 투석, 남원 인공신장실 |
| `/pediatrics/` | 소아 진료, 영유아 검진, 예방접종, 열날 때 신호 | 남원 소아과 |
| `/chronic-care/` | 고혈압·당뇨·고지혈증, 혈압 기준표 | 남원 고혈압, 남원 당뇨 |

| `/inpatient/` | 입원 치료 (폐렴·장염·교통사고·소아·투석 환자) | 남원 입원, 남원 교통사고 입원 |

## 고치는 법
- **전화·주소·진료시간·원장 이력·도메인** → `site.json` 한 곳만 고쳐요.
- **페이지 글, 자주 묻는 질문** → `_src/*.html` 에서 고쳐요. 질문은 맨 위 `faq` 목록에 넣으면 화면과 검색엔진용 데이터에 둘 다 들어가요.
- 고친 뒤 `python3 build.py` 실행 → 모든 페이지, sitemap.xml, robots.txt, llms.txt 가 새로 만들어져요.
- 만들어진 `index.html` 들은 직접 고치지 마세요 (다음 실행 때 덮어써져요).
- 사진: `assets/img/` (네이버 플레이스에 병원이 올린 사진을 줄여서 사용). 원장님 사진은 `assets/img/doctor.jpg`.

## SEO / GEO / AEO 에서 한 것
- **SEO**: 페이지마다 다른 제목·설명·검색어, canonical, sitemap, 모바일 대응, 빠른 정적 페이지
- **지역(GEO)**: 모든 페이지에 `MedicalClinic` 구조화 데이터 (주소, 좌표, 요일별 진료시간, 주차·편의시설, 결제, 근처 지역). 네이버 플레이스와 정보가 같아요.
- **답변(AEO)**: 질문형 제목 + 바로 아래 답 상자, 페이지마다 `FAQPage` (총 32개 질문)
- **AI 검색**: `llms.txt` (병원 정보 + FAQ 전체 요약), robots.txt에서 ChatGPT·Claude·Perplexity·네이버(Yeti) 허용, 원장 `Physician` 정보, 검토일 표시
- 카톡 공유 이미지 `assets/og-image.png`, 아이콘 `assets/favicon.svg`, 404 페이지

## 올리는 법 (계획 — Jae가 직접)
1. 도메인 사기 (예: 가비아, 후이즈. 1년 1~2만 원대)
2. `site.json` 의 `domain` 을 그 주소로 바꾸고 `python3 build.py`
3. Cloudflare Pages 또는 Netlify에 이 폴더를 올리고 도메인 연결 (무료)
4. 네이버 서치어드바이저·구글 서치콘솔에 사이트 등록 → 받은 인증 코드를 `site.json` 에 넣고 다시 build → sitemap 제출
5. 네이버 플레이스·블로그·인스타 프로필에 홈페이지 링크 추가
