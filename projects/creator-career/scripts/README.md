## Rules every script follows (from Mino Lee + Content Academy + 자청)
1. **ONE person.** Every account has one ideal viewer, written at the top of its file.
2. **Hook passes the 10-word test.** Clear, unique, a 10-year-old gets it.
3. **Specific beats vague.** Numbers, names, dates ("45 days", not "a while").
4. **Text hook adds new context.** It does not repeat the spoken line word for word.
5. **Pattern interrupt.** 3 to 5 cuts in the first 5 seconds.
6. **Write about the viewer, not me.** Struggles, not flexes.
7. **One main point per video.** Cut every "um" and pause. Jump cuts, no fades.
8. **Share trigger.** Each script names who the viewer would send it to.
9. **Music fits emotion.** Picks come from Mino's song list (mood in brackets).
10. **Face close, centered, colored light.** Simple, clean frame.

Hook formula tags like `[Mino: Is it possible to X in 1 day?]` show which template from the 255 Viral Hooks each one uses.
